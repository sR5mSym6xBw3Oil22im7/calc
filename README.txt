NEON BURST CALCULATOR

1. index.html をブラウザで開いてください。
2. HTML / CSS / JavaScriptのみで動作します。
3. 数字キー、四則演算、Enter、Esc、Backspaceにも対応しています。
4. 10種類のカラーバリエーションを搭載しています。
5. 起動するたびにカラーバリエーションがランダムで選ばれます。
6. 「AC」ボタンまたはEscキーで表示と数式履歴を初期化し、花火を即時消去して、現在とは異なる配色へランダムに変更します。メッセージは「SYSTEM RESET」です。
7. 「=」ボタンで計算が成功すると、花火が1秒間隔で合計5発打ち上がります。発射角度は90度・45度・135度からランダムに選択されます。
8. 数字表示の上には、現在の計算式や直前の計算履歴が表示されます。計算結果表示時に発光、画面フラッシュ、紙吹雪も発生します。
9. 花火は約30fpsで描画し、桜・バラ・菊・ユリ・蓮・ひまわりの花形からランダムに爆発します。爆発の広がりは従来版の約3倍です。
