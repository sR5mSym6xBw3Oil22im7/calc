2. プロジェクト概要

NEON BURST CALCULATORは、HTML / CSS / JavaScriptのみで構成される静的な電卓アプリです。基本的な四則演算、パーセント、小数、削除、キーボード入力に加え、計算実行時の花火・コンフェッティ演出と、日本語音声入力を備えます。

計算

加算、減算、乗算、除算、%、小数、AC、DEL。

入力

画面ボタン、キーボード、日本語音声。

演出

ランダムテーマ、粒子、花火5発、コンフェッティ、フラッシュ。

構成

バックエンド・DB・ビルド工程を持たない静的Webアプリ。

3. 開発目的

  • 一般的な電卓操作を、視覚的に強いネオン演出で体験できること。
  • キーボードだけでなく、日本語音声による計算入力を可能にすること。
  • サーバーサイド実装を持たず、静的ホスティングで配布しやすい構成を維持すること。
  • 音声認識中の状態や認識結果を画面上で確認できること。

4. 対象範囲 / 対象外

区分内容
対象四則演算、%・小数、AC/DEL、表示整形、キーボード、音声入力、演出、レスポンシブUI。
対象音声認識の開始・停止、マイク許可、認識結果表示、日本語コマンド解析。
対象外計算履歴の永続保存、ユーザー認証、サーバー処理、データベース、外部APIを用いた独自音声処理。
対象外Google Chrome for Windows 11 / Linux以外の正式動作保証。

5. 主要機能

ID機能概要実装
F-01数値入力0～9と小数点を入力。数字は最大14桁まで。実装済み
F-02四則演算＋ / − / × / ÷を実行。実装済み
F-03補助操作AC、DEL、%、Enter/Esc/Backspace等。実装済み
F-04音声入力日本語の数字・演算語・操作語を解析し、電卓操作へ変換。実装済み
F-05演出=で花火5発とコンフェッティ。テーマ色はランダム。実装済み
F-06状態表示音声入力のREADY / LISTENING / PROCESSING等を表示。実装済み

8. 動作環境

正式対応は Google Chrome for Windows 11 / Linux のみです。 それ以外は動作対象外です。実装上、Chrome以外では音声入力パネル自体を非表示にします。
項目要件
OSWindows 11 / Linux
ブラウザGoogle Chrome
JavaScript有効
音声利用マイク利用許可、SpeechRecognition互換実装、HTTPSまたは許可されたローカル開発環境
ネットワーク画面のGoogle Fonts読込と、ブラウザの音声認識実装条件に依存する可能性がある。

9. 外部依存

  • Google Fonts: Orbitron / Noto Sans JP。
  • Web Speech API: SpeechRecognition または webkitSpeechRecognition。
  • MediaDevices: navigator.mediaDevices.getUserMedia({audio:true})。

アプリ独自のバックエンド、外部計算API、外部音声APIの呼び出しコードは持ちません。

10. 制約・既知事項

ID内容影響
C-01音声入力はブラウザ提供機能に依存する。ブラウザや実行コンテキストにより利用可否が変わる。
C-02音声解析は単一の数値、単一の二項演算、相対演算、単一操作を対象とする。括弧や複合式は対象外。
C-03数値入力は画面ロジック上14桁まで。長大な数値は追加されない。
C-040除算はError。エラー表示とトーストを出す。
C-05状態・履歴を永続保存しない。再読み込みで初期化。
