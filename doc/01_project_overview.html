1. 目的

NEON BURST CALCULATOR は、一般的な電卓操作に、ネオン調UI、花火・コンフェッティ演出、日本語音声入力を組み合わせた静的Webアプリです。本書はプロジェクトの目的、対象範囲、構成、利用条件を共有するための概要書です。

2. プロジェクト概要

計算

四則演算、小数、パーセント、全消去、1文字削除を提供します。

操作

画面ボタン、キーボード、日本語音声入力の3方式で操作します。

演出

計算完了時に花火5発とコンフェッティを再生し、入力や状態に合わせて発光表現を行います。

配布

ビルド不要の静的構成で、ローカルまたは静的ホスティングで利用できます。

3. 対象範囲

区分対象
対象電卓画面、計算ロジック、キーボード操作、音声入力、演出、テーマ、レスポンシブ表示、開発文書
対象外ユーザー認証、サーバー処理、データベース、計算履歴の永続保存、クラウド同期、モバイルOS固有対応、Chrome以外の音声入力保証
正式対応Google Chrome for Windows 11 / Linux
音声利用条件マイク利用許可、SpeechRecognition対応、HTTPSまたはブラウザが許可するローカル開発環境

6. 外部機能と制約

  • Google Fonts：Orbitron と Noto Sans JP を外部読込します。通信できない場合はCSSの代替フォントで表示されます。
  • Web Speech API：音声認識はブラウザ実装に依存します。
  • MediaDevices：音声開始時に getUserMedia({audio:true}) でマイク利用可否を確認します。
  • 保存：LocalStorage、Cookie、IndexedDB等への永続保存は行いません。
アプリ独自のバックエンド、APIキー、データベースは不要です。
