1. 計算仕様

項目仕様
演算+、−、×、÷。内部表現は + - * /。
0除算結果を Error とし、「0では割れません」を表示する。
丸め計算結果を小数点以下10桁相当で丸め、文字列化する。
表示通常は日本語ロケールの桁区切り。絶対値が1e12以上、または0より大きく1e-8未満なら指数表記。
入力桁数数字は最大14桁。小数点は数値内に1つ。
%現在値を100で割る単項操作。
DEL入力中の末尾1文字を削除。演算子入力待ち・Error時は無効。
AC計算状態を初期化し、ランダムテーマを切り替える。

3. 音声入力の前提

  • ブラウザ判定はUser-Agent上のGoogle Chromeを対象とし、Edge / Opera / Samsung Browser等の他Chromium系は音声UIを非表示にします。
  • SpeechRecognition または webkitSpeechRecognition を利用し、言語は ja-JP、continuous / interimResultsを有効化します。
  • 音声開始時にマイク利用権限を確認し、停止時は取得した音声トラックを停止します。
  • 認識結果は画面上の「認識: ...」へ表示しますが、アプリ側に保存しません。

5. 音声コマンド形式

形式発話例動作
数値「12」現在の入力位置へ12を入力。
式「12たす3」12 + 3 を画面へ入力。末尾に実行語がなければ=は実行しない。
式＋実行「12たす3イコール」12 + 3 を入力し、=まで自動実行。
相対式「たす5イコール」現在値を左辺として + 5 を入力し実行。
単独操作「クリア」「削除」「パーセント」「イコール」対応する操作ボタンと同じ処理。

6. 音声状態遷移

READYREQUESTINGLISTENINGPROCESSINGSUCCESS（定義のみ）LOCKEDERRORUNSUPPORTED
READY待機
→
REQUESTINGマイク権限確認
→
LISTENING認識中
→
PROCESSING解析・入力反映
→
LISTENING継続待受

「イコール」等を末尾で検出すると、計算演出完了まで LOCKED に遷移します。SUCCESSは表示文言として定義されていますが、現行コードの通常フローでは遷移に使用されません。花火完了後は音声セッションが継続中であればLISTENINGへ戻ります。

7. タイミングとエラー

  • 音声で数値を入力する際、各キーの発光演出は1文字ごとに1秒間隔で進みます。
  • =実行時の花火は5発、発射間隔は1秒です。
  • 無音状態が30秒続くと表示状態をREADY相当に戻しますが、ブラウザ認識の再起動処理はセッション状態に従います。
  • 認識不能、マイク権限エラー等では計算画面を初期化し、「音声入力でエラーが発生しました」を3秒間表示します。
Web Speech APIの認識可否・精度・ネットワーク要件はChrome側の実装や環境に依存します。
