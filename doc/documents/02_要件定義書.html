5. 本文

5.1 システム化の目的・利用者要件

  • ブラウザ上で直感的に四則演算できること。
  • ボタンまたはキーボードから同等の操作を行えること。
  • 計算結果を視認しやすく表示し、演出で操作完了を認識できること。

5.2 機能要件

機能要件
要件ID分類要件名要件内容優先度根拠ファイル備考
FR-001入力数字入力0～9を入力できる。必須script.js inputDigit、data-number14桁まで
FR-002入力小数点入力「.」または「,」から小数点を1回入力できる。必須script.js inputDecimal、keydown重複入力は無視
FR-003計算四則演算加算、減算、乗算、除算を実行できる。必須calculate、chooseOperator、evaluateゼロ除算はエラー
FR-004計算パーセント現在値を100で除算する。必須percent単項処理
FR-005編集AC状態を全消去し、テーマをランダム変更する。必須clearAll(true)SYSTEM RESET表示
FR-006編集DEL現在値を1文字削除する。必須backspace待機中とError時は無処理
FR-007表示計算式・結果表示式、結果、表示メーターを更新する。必須updateDisplay、output要素結果は桁区切り
FR-008表示数値整形14桁入力制限、指数表記、10桁丸めを行う。必須inputDigit、formatValue、normalizeResult1e12以上等は指数表記
FR-009異常ゼロ除算Errorと「0では割れません」を表示し復帰可能とする。必須calculate、handleError次の数字入力または演算子で復帰
FR-010操作キーボード数字、四則、Enter、=、Esc、Backspace、.、,、%を処理する。必須document keydown該当キーはpreventDefault
FR-011演出計算完了演出=でコンフェッティ120個と花火5発を1秒間隔で起動する。必須triggerMegaEffect、startFireworks単独=でも演出起動
FR-012テーマランダムテーマ初期表示とAC時に10テーマから選択する。任意themes、applyRandomThemerainbowを含む
FR-013描画Canvas制御リサイズとページ非表示時に花火を停止する。推奨resizeCanvases、visibilitychangeCanvas 2D

非機能要件

5.4 UI・UX／対応環境

UI・環境要件
項目要件
UIネオン調の単一電卓画面、計算式表示、結果表示、メーター、4列キー配列。
操作マウスクリック、タッチ由来のclick、キーボード。
対応環境確定した実績はWindows 11、Google Chrome、1920×1080およびスマートフォン幅表示。
外部通信Google Fonts取得時のみ外部通信が発生する。
可用性GitHub Pagesが利用可能で、静的ファイルが取得できること。

5.5 受入条件

  • 主要計算機能、マウス操作、キーボード操作および画面表示に問題がないこと。
  • GitHub Pagesの公開先URLでindex.html、style.css、script.jsを取得できること。
  • ゼロ除算後にError表示と復帰操作が成立すること。
