2. 目的

現行実装の方式と、今後の変更に適用する推奨規約を区別して定義する。

3. 適用範囲

HTML、CSS、JavaScriptの編集、ローカル確認、コードレビューおよびGitHub Pages公開前確認を対象とする。

4. 用語・略語

用語・略語
用語・略語説明
静的WebアプリケーションHTML、CSS、JavaScriptのみでブラウザ上に動作するアプリケーション。
DOMDocument Object Model。JavaScriptからHTML要素を参照・更新する仕組み。
Canvasパーティクルおよび花火を描画するHTML要素。
GitHub Pages本システムの確定した本番公開環境。
EFSZIPのファイル名がUTF-8であることを示すGeneral Purpose Bit Flagの第11ビット。

5. 本文

5.1 現行実装で採用されている方式

現行方式
項目現行方式
開発環境テキストエディタとモダンブラウザ。ビルド不要。
起動index.htmlを直接開く、または静的Webサーバーで配信する。
HTMLlang=ja、UTF-8、セマンティック要素、data属性による操作識別。
CSSstyle.css 1ファイル、CSS変数、Grid、color-mix、@keyframes、2メディアクエリ。
JavaScriptIIFEとstrict mode、let/const、DOM API、Canvas 2D、イベント委譲。
文字コードUTF-8。
依存Google Fontsのみ。npm、package.json、ビルドツール、テストフレームワークは実装なし。

5.2 ローカル起動方法

  1. index.htmlをブラウザで開く。
  2. HTTP配信が必要な場合はソースディレクトリでpython -m http.server 8000を実行する。
  3. http://localhost:8000/を開き、開発者ツールにエラーがないことを確認する。

5.3 今後の推奨規約

推奨規約
分類規約
HTMLIDはDOM参照に必要な要素だけに付与し、buttonにはtype="button"を明示する。
CSSテーマ色はCSSカスタムプロパティへ集約し、既存のdata-theme名を維持する。
JavaScript状態更新とDOM反映の順序を明確にし、textContentを使用する。
命名関数は動詞から始めるcamelCase、定数はUPPER_SNAKE_CASE、CSSクラスはkebab-case。
インデント半角スペース2つ。
コメント定数の意図や非自明なアルゴリズムを説明し、処理の逐語訳は避ける。
イベント重複リスナーを避け、キー操作では対象キーのみpreventDefaultする。
エラー非有限値をErrorへ集約し、復帰可能な状態を維持する。
CanvasdevicePixelRatio上限、配列上限、フレーム間隔を維持・測定する。
アクセシビリティaria-live、aria-hidden、prefers-reduced-motionを回帰確認する。

5.4 変更時の確認事項

  • 関数名、HTML ID・クラス、data属性、キー割当を文書と同期する。
  • 最大14桁、指数表記閾値、10桁丸め、花火5発・1秒間隔・約30fpsを変更した場合は関連文書とテストを更新する。
  • 外部フォントURL、フォールバック、GitHub Pagesのパスを確認する。
  • レスポンシブ変更は540px境界とCanvas粒子数700px境界を別々に確認する。

5.5 コードレビューチェックリスト

レビュー項目
No.確認項目
1UTF-8で保存されている。
2HTMLの参照パスと閉じタグが正しい。
3グローバル変数を追加していない。
4Error状態とゼロ除算を回帰確認した。

6Canvas配列が無制限に増えない。
7prefers-reduced-motionを維持している。
8Google Fonts未取得時も本文と数字が読める。
9PC幅とスマートフォン幅で表示崩れがない。
10関連する文書IDとテストIDを更新した。

5.6 禁止事項

  • ソースに存在しないAPI、データベース、認証、サーバー処理を現行仕様として追加しない。
  • ユーザー入力をinnerHTMLへ直接代入しない。
  • 花火・粒子の上限を根拠なく撤廃しない。
  • 圧縮済みファイルだけを原本として管理しない。

6. 前提条件・制約事項

使用しない構成

現行構成にnpm、package.json、トランスパイル、バンドル、ミニファイ、CI/CDは存在しない。

7. 補足事項

推奨事項

自動テスト導入は推奨事項であり、現行実装で採用済みの方式ではない。
