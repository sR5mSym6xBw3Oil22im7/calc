2. 目的

電卓Webアプリケーションの全体像、開発対象、技術構成、成果物、制約およびリスクを関係者間で共有することを目的とする。

3. 適用範囲

calc-main.zipに含まれる4ファイルと、それらがブラウザで提供する計算・表示・演出機能を対象とする。

4. 用語・略語

用語・略語
用語・略語定義
静的WebアプリケーションHTML、CSS、JavaScriptをブラウザで直接実行する構成。
DOMDocument Object Model。HTML要素をJavaScriptから操作する仕組み。
CanvasJavaScriptで2次元描画を行うHTML要素。
IIFE即時実行関数式。script.js全体を閉じたスコープで実行する方式。
逐次計算入力順に演算を確定する方式。一般的な演算子優先順位は適用しない。

5.2 主要機能

  • 0～9、小数、四則演算、%、AC、DEL、=。
  • マウス/互換タッチおよびキーボード操作。
  • 式表示、結果表示、入力桁メーター、桁区切り、指数表記、10桁丸め。
  • 10テーマ、リップル、傾き、トースト、背景粒子、コンフェッティ、5発の花火。

5.8 リスクと対応方針

主要リスク
リスク影響対応方針
外部フォント取得失敗字幅・印象の変化sans-serifで機能継続。必要に応じてローカル配布方針を検討。
Canvas負荷低性能端末でカクつきDPR・粒子上限を維持し、実機性能試験を行う。
Deleteキー未対応期待する利用者が削除できない要件合意後にkeyMapへ追加。
reduced-motion不完全Canvas演出が継続JS側でmatchMediaを確認し停止する改善を検討。
ブラウザ差異color-mix/backdrop-filter等の差対象ブラウザを確定し互換性テストを行う。

6. 前提条件・制約事項

  • 本システムは静的Webアプリケーションであり、バックエンドAPI、Web API、データベース、認証、サーバーサイド処理、バッチ、管理画面を使用しないため対象外である。
  • package.json、npm、ビルドツール、テストフレームワーク、CI/CD、コンテナは存在しない。
  • README.mdと実装が異なる場合は実装を正とする。
  • 公開先URL、本番環境、担当者、承認者、日程はソースコードから確認できない。
