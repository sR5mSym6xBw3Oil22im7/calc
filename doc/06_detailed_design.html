1. JavaScript構成

script.js はIIFE内に63個の関数を持ち、グローバル名前空間への公開を避けています。処理は概ね下表の責務に分かれます。

領域主要関数責務
CanvasresizeCanvas, resizeCanvases, animateParticles背景パーティクル、Canvasサイズ。
花火launchFirework, explodeFirework, startFireworks, animateFireworksロケット、花形スパーク、5発演出。
計算inputDigit, inputDecimal, calculate, chooseOperator, evaluate, percent入力、演算、結果、丸め。
表示formatValue, updateDisplay, showToast, createRipple表示整形、DOM更新、押下演出。
音声状態setVoiceState, resetVoiceInput, startVoiceRecognition音声セッションとUI状態。
音声解析normalizeVoiceText, parseJapaneseNumber, parseVoiceCommand日本語表現をコマンドへ変換。
音声実行inputVoiceNumber, activateVoiceKey, executeVoiceCommand画面キー発光と計算処理の同期。
初期化setupVoiceInputForBrowser, applyTheme, applyRandomThemeブラウザ判定、テーマ、起動処理。

2. 計算シーケンス

数字入力currentValue更新
→
演算子previousValue保存
→
右辺入力currentValue更新
→
= 実行calculate
→
結果・演出updateDisplay / fireworks

計算時の要点

  • 演算子を連続入力する前に右辺が存在する場合は、その時点の式を先に評価します。
  • normalizeResult() で非有限値をErrorへ変換し、小数誤差を抑えるため1e10基準で丸めます。
  • =実行後は previousValue と operator をnullへ戻し、waitingForOperand=true とします。

3. 音声認識シーケンス

マイク押下REQUESTING
→
getUserMedia権限確認
→
Recognition.startLISTENING
→
onresult文字列正規化
→
Command実行DOM/計算反映
  1. 中間認識も表示し、最終認識のみコマンド実行へ渡します。
  2. 発話末尾に実行語を検出した時点で入力をLOCKEDにします。
  3. Recognitionが終了しても利用者が待受継続を希望していれば100ms後に再起動を試みます。
  4. InvalidStateErrorは即エラーにせず再起動へ回します。

5. テーマ

テーマ候補は rainbow / plasma / gold / lime / sakura / ocean / inferno / ice / candy / royal の10種類です。body.dataset.theme を通じてCSS変数の組合せを変更します。

6. エラー処理

ケース処理
0除算currentValue=Error、計算状態初期化、振動演出、Toast表示。
音声コマンド不明音声入力エラーとしてセッション停止、画面初期化、ERRORを3秒表示。
マイク拒否/認識エラー音声ストリーム停止、計算入力ロック解除、画面初期化。
花火中リサイズCanvasを再計算し、実行中花火を停止。
タブ非表示花火アニメーションを停止。
