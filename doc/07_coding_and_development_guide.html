1. ファイル責務

ファイル責務変更時の注意
index.htmlDOM構造、ボタン属性、ARIA、CanvasJavaScriptが参照するID/data属性を変更する場合はscript.jsも同期する。
style.cssテーマ、配置、アニメーション、レスポンシブCSS変数とdata-themeの対応を維持する。
script.js計算、音声、状態管理、Canvas入力方式間で同じ処理関数を共有する設計を維持する。
README.md利用者向け説明対応環境・音声仕様・ファイル構成の変更を反映する。
doc/開発・納品向け文書工程別ナビゲーションと相互リンクを維持する。

2. コーディング規約

  • JavaScriptは現行どおり 'use strict' とIIFEを維持し、不要なグローバル変数を作らない。
  • DOMへの利用者入力表示は原則 textContent を使用する。
  • 数値状態は表示用文字列と演算時のNumber変換を意識し、Error状態を明示的に扱う。
  • 入力経路を追加する場合も、最終的な計算処理は既存の inputDigit()、chooseOperator()、evaluate() 等へ寄せる。
  • 音声認識状態と計算入力ロックを混同しない。花火中ロック解除のコールバックを維持する。
  • アニメーション追加時は prefers-reduced-motion の対象に含める。
  • 文字コードはUTF-8、改行コードはリポジトリの既存規約に合わせる。

3. ローカル確認

単純な表示確認は index.html を直接開けます。音声入力を含む確認では、ブラウザのセキュアコンテキスト条件を満たすため、localhost上での配信を推奨します。

cd calc-main
python -m http.server 8000
# Google Chrome で http://localhost:8000/ を開く
音声認識はChromeの機能・権限・環境に依存します。自動テストのみで完了とせず、Windows 11 / Linux のChromeで実マイク確認を行います。

4. 変更手順

  1. 変更対象と影響範囲を特定する。
  2. アプリ本体を修正する。
  3. 画面ボタン、キーボード、音声入力の同等性を確認する。
  4. Chromeでエラー・コンソール例外を確認する。
  5. 該当するREADMEとdoc文書を更新する。
  6. 静的ファイルの相対パス、文字化け、リンク切れを確認する。

5. レビュー観点

分類確認事項
計算入力桁数、小数、連続演算、0除算、丸め。
入力ボタン/キーボード/音声で結果が一致するか。
音声開始・停止・再起動・エラー・LOCKED解除が成立するか。
UI540px以下、長い数値、Reduced Motion、ARIA。
性能Canvas配列上限、タブ非表示時停止、resize時停止。
文書READMEとdocの仕様が実装と矛盾していないか。
