NEON BURST CALCULATOR 開発ドキュメント一式

1. 目的
calc-main.zipに含まれる静的電卓Webアプリを解析し、要件定義から運用保守までを追跡可能な形で文書化したものです。

2. フォルダ構成
calc-main-documents/
  index.html
  css/style.css
  css/print.css
  js/document.js
  documents/01_プロジェクト概要書.html ～ 10_運用保守手順書.html
  README.txt

3. 各文書の概要
  DOC-01 プロジェクト概要書: 本プロジェクトの背景、目的、範囲、構成、成果物およびリスクを俯瞰する。
  DOC-02 要件定義書: 利用者要件、機能要件、非機能要件および受入条件を定義する。
  DOC-03 UI・画面設計書: 単一画面の構造、画面項目、操作、配色、演出およびアクセシビリティを定義する。
  DOC-04 計算機能設計書: 入力、演算、状態管理、表示整形、異常処理の設計を定義する。
  DOC-05 プログラム詳細設計書: HTML、CSS、JavaScriptの構成、関数、イベント、依存関係を定義する。
  DOC-06 開発・コーディングガイド: 現行実装方式と今後の推奨規約を分けて示す。
  DOC-07 テスト計画・テスト仕様書: テスト方針、環境、判定基準および具体的なテストケースを定義する。
  DOC-08 テスト結果報告書: 自動実行・静的確認の結果と未実施項目、残存課題、リリース判定を報告する。
  DOC-09 リリース手順書: ローカル配布と静的Webサーバー配置の手順、確認、ロールバックを定義する。
  DOC-10 運用保守手順書: 静的Webアプリとして現実的な確認、障害対応、変更管理を定義する。

4. 閲覧方法
index.htmlをブラウザで開いてください。各文書はカードから遷移できます。JavaScriptが無効でも本文とリンクは閲覧できますが、メニュー開閉、検索、テーマ保持、印刷ボタン、上部へ戻るボタンは利用できません。

5. ローカルWebサーバー例
python3 -m http.server 8000 --directory calc-main-documents
その後、ブラウザで http://localhost:8000/ を開きます。

6. 外部リソース
本ドキュメントサイト自体は外部CSS/JavaScript/フォントを読み込みません。解析対象の原アプリはGoogle FontsからOrbitronとNoto Sans JPを取得します。

7. 更新方法
ソース変更時はDOC-02の要件、DOC-03/04の設計、DOC-05の関数/イベント、DOC-07/08のテスト、DOC-09/10の手順を同時に更新してください。ID形式を維持してください。

8. 要確認事項
開発担当者、文書作成者、承認者、利用組織、公開先URL、リリース日時、本番環境、保守担当者、対応期限、実際のプロジェクトスケジュールは要確認です。
