対象システム

項目内容
名称NEON BURST CALCULATOR
構成HTML / CSS / JavaScript の静的Webアプリ
主要機能四則演算、%・AC・DEL、小数、キーボード入力、音声入力、花火・コンフェッティ演出、ランダムテーマ
正式対応ブラウザGoogle Chrome for Windows 11 / Linux
音声認識Web Speech API（SpeechRecognition / webkitSpeechRecognition）、言語 ja-JP
永続データなし。計算状態・認識結果はブラウザ実行中のメモリ上で扱う。
外部通信Google Fontsの読込、およびブラウザが提供する音声認識機能。アプリ独自のバックエンド/APIは持たない。
