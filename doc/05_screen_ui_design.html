MOCの目的
実装済みの画面構造を文書用に簡略再現しています。配色・発光・花火の厳密な見た目は実画面を正とします。
  • 最上部：製品名
  • 表示部：式、主結果、メーター
  • 音声部：状態、開始/停止、説明、認識結果
  • 入力部：4列キー配置
  • 下部：キーボードガイド

2. 画面項目定義

ID項目表示/操作
UI-001タイトルMAXIMUM EFFECT MODE / NEON BURSTを表示。
UI-002式表示直前の左辺・演算子・右辺・=を右寄せ表示。空時はREADY演出。
UI-003主表示現在値/結果を大きく表示。長い値は省略表示。
UI-004表示メーター入力桁数に応じ18%を基点に最大100%まで伸長。
UI-005音声状態READY等の英字状態と日本語メッセージ。
UI-006音声ボタン開始時は「停止」、待機時は「音声入力」。aria-pressedを更新。
UI-007認識結果「認識: —」または認識文字列。
UI-008キー数字、AC、DEL、%、四則演算、小数点、=。
UI-009ToastSYSTEM RESET、0除算、花火実行等を一時表示。

3. レスポンシブ

  • 基本幅は電卓最大520px。
  • 画面幅540px以下では外側余白、電卓内余白、表示部、キー高さ・角丸を縮小します。
  • Canvasはウィンドウサイズに追従し、devicePixelRatioを上限付きで利用します。
  • 横方向のはみ出しを抑制し、単一カラムで操作できる構成です。

4. アクセシビリティ

観点対応
意味のある要素計算キーはbutton、表示はoutputを使用。
音声操作音声ボタンにaria-label / aria-pressed。
状態通知主表示、音声状態、Toastにaria-live / role=statusを利用。
装飾Canvasaria-hiddenで支援技術から除外。
モーションprefers-reduced-motionでアニメーションを実質停止。

5. 表示状態

通常数値入力演算待ち結果ErrorVoice LISTENINGVoice LOCKED

音声LOCKED中は、キーパッドとキーボード入力を処理しません。画面上のキーは音声入力内容に合わせて順番に発光します。
