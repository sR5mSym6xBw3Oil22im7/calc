1. 画面概要

画面は単一ページで、上からタイトル、2段ディスプレイ、音声入力パネル、4列キーパッド、キーボードガイドの順に配置します。背景には固定Canvasとオーロラ・グリッド演出を重ねます。

4. レスポンシブ仕様

条件変更
通常電卓幅は最大520px、外側padding 32px 18px 52px。
最大幅540pxapp-shell、calculator、display-panelの余白を縮小。キーはmin-height 60px、font-size 20px。
全幅4列キーパッドを維持。0キーは2列幅。

5. 色・テーマ

テーマはrainbow / plasma / gold / lime / sakura / ocean / inferno / ice / candy / royalの10種です。初期表示でランダム選択し、AC時は現在テーマ以外から再選択します。

6. 音声UI状態

状態ボタンパネル表現
READY音声入力待機
REQUESTING停止マイク許可確認
LISTENING停止ボタンをパルス表示
PROCESSING停止解析中
LOCKED無効花火演出中
ERROR音声入力エラー色
UNSUPPORTED無効非対応表示。ただし非Chromeではパネル非表示。

7. アクセシビリティ設計

  • calculatorにaria-label。
  • mainDisplay / voiceStatusにaria-live="polite"。
  • 音声ボタンにaria-labelとaria-pressed。
  • Canvasはaria-hidden="true"で装飾扱い。
  • prefers-reduced-motion: reduceでアニメーションを最小化。
  • 音声ボタンのfocus-visibleに明確なアウトライン。
