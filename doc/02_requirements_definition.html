1. 要件の目的

利用者がボタン、キーボード、音声のいずれからでも直感的に計算でき、計算結果を視覚演出とともに確認できることを目的とします。

2. 機能要件

ID要件内容状況
FR-001数値入力0～9を入力し、整数部を最大14桁まで保持する。実装済み
FR-002小数入力1つの数値につき小数点を1回入力できる。実装済み
FR-003四則演算加算、減算、乗算、除算を行う。実装済み
FR-004連続演算演算子入力時に未確定の計算を評価し、次の演算へ継続できる。実装済み
FR-005パーセント表示中の数値を100で割った値に変換する。実装済み
FR-006削除・初期化DELで1文字削除、ACで計算状態を初期化する。実装済み
FR-007キーボード数字、四則演算、Enter/=、Esc、Backspace、%、小数点を受け付ける。実装済み
FR-008音声入力Google Chromeで日本語音声を認識し、数値・演算・操作へ変換する。実装済み
FR-009音声状態表示READY、REQUESTING、LISTENING、PROCESSING、LOCKED、ERROR、UNSUPPORTEDを画面表示する。SUCCESSは表示定義のみ存在し、現行処理では遷移先として使用しない。実装済み
FR-010計算演出= 実行時に表示アニメーション、コンフェッティ、花火5発を再生する。実装済み
FR-011テーマ起動時に10種類からランダムテーマを適用し、AC時は別テーマへ切り替える。実装済み
FR-012エラー0除算または音声認識失敗時にエラー状態を表示し、安全に状態を戻す。実装済み

3. 非機能要件

ID分類要件
NFR-001対応環境Google Chrome for Windows 11 / Linuxを正式対応とする。
NFR-002レスポンシブ狭幅では540px以下のCSS調整を適用し、電卓操作が継続できること。
NFR-003アクセシビリティ主要操作にbutton要素、aria-label、aria-live等を使用する。
NFR-004モーション配慮prefers-reduced-motion: reduce ではアニメーション時間を最小化する。
NFR-005データ保護計算値・音声認識結果をアプリ独自に永続保存しない。
NFR-006保守性HTML/CSS/JSの責務を分離し、外部ビルドを不要とする。
NFR-007文字コードアプリ・README・開発文書をUTF-8で扱う。

4. 受入条件

  1. 正式対応環境で画面が表示され、0～9、四則演算、小数、%、AC、DEL、= が操作できる。
  2. キーボード操作が対応する画面ボタンと同じ結果になる。
  3. 0除算時に Error と「0では割れません」の通知が表示される。
  4. = 実行後に結果が表示され、花火・コンフェッティ演出が開始される。
  5. Google Chromeでは音声入力パネルが表示され、マイク許可後に日本語音声を認識できる。
  6. 「12たす3イコール」のような対応表現で計算結果15が得られる。
  7. 音声による=処理中はLOCKEDとなり、演出終了までキーボード・ボタン入力を受け付けない。
  8. Chrome以外では音声入力パネルが非表示となり、通常の電卓機能は利用できる。

5. 対象外要件

  • 計算履歴の保存・検索
  • 関数電卓・三角関数・指数関数
  • サーバー同期、アカウント、共有
  • 音声認識精度そのものの保証
  • Chrome以外のブラウザ、Windows 11 / Linux以外のOSでの動作保証
