2. 画面コンポーネント

DOM役割
#calculator電卓本体。傾き、発光、エラー振動、オーバードライブ演出の基準。
#expressionDisplay左辺・演算子・右辺・=の式表示。
#mainDisplay現在値・計算結果の主表示。
#voicePanel音声状態、開始/停止、ステータス、認識結果。
#keypad数字、演算子、ユーティリティボタン。
#particleCanvas背景パーティクル。
#fireworksCanvas花火ロケット・火花描画。
#toastエラーや演出メッセージを一時表示。

3. 主要状態

状態型/例用途
currentValue文字列主表示の現在値。
previousValue文字列 / null二項演算の左辺。
operator+ - * / / null選択中の演算子。
waitingForOperandboolean次の数値入力待ち。
expressionText文字列式表示。
calculatorInputLockedboolean音声=処理から花火完了までの入力抑止。
voiceListeningRequestedboolean利用者が音声待受を希望しているか。
currentVoiceStateIDLE等音声UI状態。
fireworkRockets / fireworkSparks配列Canvas上の花火描画状態。

4. イベント設計

イベント入口処理
ボタンクリック#keypad clickprocessButton() で数値・演算・アクションへ振り分け。
キーボードdocument keydownキーをセレクタへ変換し、対象ボタンを押下表示後に同じ処理を実行。
音声ボタン#voiceButton click権限確認、認識開始/停止、音声ストリーム解放。
SpeechRecognitiononstart/onresult/onerror/onend状態更新、コマンド変換、再起動、エラー復旧。
マウス移動#calculator mousemove電卓全体に軽い3D傾き。
resizewindow resizeCanvas再計算、実行中花火停止。
visibilitychangedocument visibilitychange非表示時に花火停止。

5. 外部依存

依存用途障害時
Google FontsOrbitron / Noto Sans JP代替フォントで継続表示。
Web Speech API日本語音声認識API非対応なら音声ボタン無効またはパネル非表示。
MediaDevicesマイク権限確認利用不可/拒否時は音声エラー。
Canvas 2D背景・花火描画演出機能に影響。電卓DOMとは分離。

6. セキュリティ・プライバシー

  • ユーザー入力を textContent で表示し、認識テキストをHTMLとして挿入しません。
  • アプリ側に認証情報、APIキー、永続ストレージはありません。
  • マイクストリームは音声停止時・リセット時にトラックを停止します。
  • 音声データの処理経路はブラウザ提供機能に依存するため、運用時はChromeの仕様・プライバシー条件を確認します。
