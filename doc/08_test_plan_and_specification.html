1. テスト方針

計算結果の正しさ、3つの入力経路の同等性、音声状態遷移、エラー復旧、表示崩れを中心に手動確認します。本書はテスト仕様を定義するものであり、個別ケースの実施結果は実行時に記録します。

2. テスト環境

環境ブラウザ必須確認
Windows 11Google Chrome 最新安定版全機能、マイク権限、音声入力
LinuxGoogle Chrome 最新安定版全機能、マイク権限、音声入力
参考確認Chrome以外音声パネル非表示と通常電卓の継続利用。正式対応外。

ID操作期待結果

TC-00512 - 3 =9。

TC-00812 / 0 =Error、「0では割れません」。

TC-0122 + 3 + 4 =演算子選択時に途中評価し、9。
TC-01315桁以上を入力数字部は14桁を超えて追加されない。

5. 音声テスト

ID発話/操作期待結果
TC-V01音声入力ボタンREQUESTING後、許可済みならLISTENING。
TC-V02「12たす3イコール」キーが順次発光し、15を表示、=から演出終了までLOCKED。
TC-V03「10かける5イコール」50。
TC-V04「たす5イコール」現在値+5を計算。
TC-V05「クリア」AC処理。
TC-V06「削除」DEL処理。
TC-V07「いちてんごたすにイコール」3.5。
TC-V08未対応表現ERROR、「音声入力でエラーが発生しました」を3秒表示後READYへ。
TC-V09マイク拒否ERRORとなり、計算画面が初期化。
TC-V10音声停止ボタン認識停止、マイクトラック解放、READYへ。
