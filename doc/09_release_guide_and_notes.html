1. リリース対象

アプリ本体のindex.html、style.css、script.js、README.md、およびdoc/を同一プロジェクトとして静的ホスティングへ配置します。

2. リリース前条件

  • DOC-08のWindows 11 / Linux Chromeテストを完了している。
  • 音声利用ページがHTTPSで配信される、または正式なローカル検証条件を満たす。
  • マイク権限拒否時にもアプリの計算機能が継続できることを確認する。
  • 公開先のCSP等がGoogle Fontsや必要なブラウザ機能を妨げないことを確認する。

3. 配置手順

  1. 対象ファイルを公開ディレクトリへ配置。
  2. 相対パスを維持し、index.htmlからstyle.cssとscript.jsを読み込めることを確認。
  3. HTTPS URLをChromeで開く。
  4. 初期表示、ボタン計算、キーボード計算を確認。
  5. マイクを許可し、代表発話「12たす3イコール」を確認。
  6. /doc/index.htmlから10文書を開けることを確認。

4. GitHub Pagesでの公開例

本アプリは静的ファイルのみで構成されるため、GitHub Pages等の静的ホスティングに適します。公開URL自体は本ZIP内の現行情報では固定していないため、本書では特定URLを決め打ちしません。

音声入力を正式に確認する公開先はHTTPSを使用してください。

5. リリース後スモークテスト

No.確認項目期待
1トップ表示レイアウト・フォント・キーが表示。
21+2=3。
3花火=で演出。
4マイクChromeでパネル表示、許可要求。
5音声計算「12たす3イコール」→15。
6権限拒否ERROR表示、通常計算は継続。
7ドキュメントdoc/index.htmlと各リンクが404にならない。

6. ロールバック

  1. 不具合版の公開を停止。
  2. 直前に検証済みの静的ファイル一式へ戻す。
  3. ブラウザキャッシュの影響を避けて再確認。
  4. 計算・音声・ドキュメントのスモークテストを再実施。
  5. 不具合原因と修正版を別途記録。

7. リリースノート（音声入力対応版）

  • Google Chrome for Windows 11 / Linux向け日本語音声入力を搭載。
  • VOICE INPUTパネル、認識状態、認識文字列を追加。
  • 日本語の四則演算語・操作語・一部のかな/漢数字を解析。
  • 音声による=評価では花火中の追加入力をロック。
  • 音声停止時にマイクMediaStreamを解放。

8. 既知の制約

ID制約運用対応
RN-01正式対象はWindows 11 / LinuxのChromeのみ。他ブラウザはサポート対象外。
RN-02音声認識精度はブラウザ/マイク/環境音に依存。認識文字列を見て再発話。
RN-03複合式や自由会話は非対応。「数値＋演算語＋数値＋イコール」の形式を推奨。
RN-04アプリは履歴を保存しない。必要な結果は別途記録。
