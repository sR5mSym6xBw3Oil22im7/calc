1. リリース対象

index.html style.css script.js README.md doc/ index.html 01_project_overview.html ～ 10_user_and_operations_manual.html css/style.css

外部ビルド成果物はありません。上記静的ファイルを同じ相対配置で公開します。

2. リリース前確認

  1. index.html / style.css / script.js の相対参照が成立すること。
  2. README.md と doc/ の仕様がリリース対象ソースと一致すること。
  3. Windows 11 / Linux のGoogle Chromeで主要テストを実施すること。
  4. 音声入力用にマイク権限を確認し、公開環境がHTTPSであること。
  5. doc/index.htmlから全10文書へ遷移できること。
  6. UTF-8で文字化けがないこと。

3. GitHub Pages等への公開手順

  1. リリース対象ファイルをリポジトリへ反映する。
  2. 公開ブランチ/ディレクトリの設定を確認する。
  3. 公開URLでトップ画面を表示する。
  4. Google Fontsが読めない場合も代替フォントで操作できることを確認する。
  5. HTTPSページ上で音声入力を実機確認する。
  6. doc/を公開対象に含め、文書リンクを確認する。
音声認識は静的ファイルだけで完結する機能ではなく、Chrome側のSpeechRecognition実装に依存します。

4. ロールバック

  1. 不具合を検知したリリースの公開を停止または直前コミットへ戻す。
  2. index.html / style.css / script.js / README.md / doc/ を同一世代で戻す。
  3. キャッシュ影響を確認し、公開URLで再確認する。
  4. 音声入力不具合の場合は、Chromeバージョン・OS・マイク権限も記録する。

6. 既知の制約

  • 音声認識の可用性・精度はGoogle Chromeおよび実行環境に依存します。
  • 正式対応環境外の動作は保証しません。
  • Google Fontsはネットワーク状態により取得できない場合があります。
  • 計算履歴・設定・認識結果を永続保存しません。
