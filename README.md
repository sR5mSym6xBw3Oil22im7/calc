# NEON BURST CALCULATOR

ネオン演出と花火アニメーションを備えた、HTML / CSS / JavaScript だけで動作する電卓アプリです。

## 特徴

- `index.html` をブラウザで開くだけで動作します
- 基本的な四則演算に対応しています
- `%`、`AC`、`DEL`、小数点入力に対応しています
- `=` を押すと、前回の演出をリセットしたうえで花火とコンフェッティの演出が発生します
- 花火は常に上方向から打ち上げられる演出に統一されています
- テーマカラーがランダムに切り替わる、サイバー風のビジュアルです
- キーボード操作にも対応しています
- Google Chrome（Windows 11 / Linux）では、マイクボタンから日本語の音声入力に対応しています
- 画面サイズに応じて表示が最適化されるレスポンシブUIです

## 使い方

1. `index.html` をブラウザで開きます
2. 数字ボタンまたはキーボードで数値を入力します
3. 演算子を選んで計算します
4. `=` で計算結果を表示し、演出を再生します

## 操作方法

- 数字: `0` - `9`
- 四則演算: `+` `-` `*` `/`
- 小数点: `.` または `,`
- パーセント: `%`
- クリア: `AC` または `Esc`
- 1文字削除: `DEL` または `Backspace`
- 計算実行: `=` または `Enter`（押すたびに演出が更新されます）

### 音声入力

Google Chrome for Windows 11 / Linuxで、マイクボタンを押してから次のように話してください。

- 「12たす3イコール」
- 「10かける5イコール」
- 「クリア」

初回利用時はChromeのマイク使用許可が必要です。音声認識はブラウザのWeb Speech APIを利用し、アプリ側で音声や認識結果を保存しません。HTTPS環境（またはローカル開発環境）で利用してください。上記以外のブラウザ・OSは正式サポート対象外です。

## ファイル構成

- `index.html`: 画面構成
- `style.css`: デザイン、アニメーション、レスポンシブ対応
- `script.js`: 計算ロジック、キーボード操作、花火演出

## 実行環境

特別なビルド手順は不要です。モダンなブラウザでそのまま開けます。
