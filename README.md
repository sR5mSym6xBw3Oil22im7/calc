# NEON BURST CALCULATOR

ネオン演出と花火アニメーションを備えた、HTML・CSS・JavaScriptだけで動作する電卓アプリです。

## 特徴

- `index.html`をブラウザで開くだけで動作
- 基本的な四則演算に対応
- `%`、`AC`、`DEL`、小数点入力に対応
- `=`を実行すると、計算結果の表示と花火・コンフェッティ演出を再生
- キーボード操作に対応
- Google Chrome（Windows 11 / Linux）で日本語の音声入力に対応
- 音声入力中の状態を`LISTENING`、`LOCKED`、`ERROR`などで表示
- 画面サイズに応じて表示を最適化するレスポンシブUI
- テーマカラーがランダムに切り替わるサイバー風のデザイン

## 使い方

1. `index.html`をブラウザで開きます。
2. 数字ボタンまたはキーボードで数値を入力します。
3. 演算子を選択して計算式を作成します。
4. `=`を押すと計算結果が表示され、演出が再生されます。

## 操作方法

- 数字: `0`〜`9`
- 四則演算: `+`、`-`、`*`、`/`
- 小数点: `.` または `,`
- パーセント: `%`
- クリア: `AC` または `Esc`
- 1文字削除: `DEL` または `Backspace`
- 計算実行: `=` または `Enter`

## 音声入力

Google Chrome for Windows 11 / Linuxでマイクボタンを押し、次のように話してください。

- 「12たす3イコール」
- 「10かける5イコール」
- 「クリア」

音声入力で「イコール」を認識すると、音声入力はただちに`LOCKED`状態になります。`=`キーの演出が完了したあとに花火が再生され、演出終了後も音声入力は`LISTENING`状態を維持します。ロック中は音声入力およびキーボード入力を受け付けません。

初回利用時は、ブラウザによるマイク使用許可が必要です。音声認識にはブラウザのWeb Speech APIを使用しています。音声や認識結果はアプリ側で保存しません。GitHub PagesなどのHTTPS環境、またはローカル開発環境で利用してください。

音声入力でエラーが発生した場合は、画面を初期化し、「音声入力でエラーが発生しました」というメッセージを3秒間表示します。

## ファイル構成

- `index.html`: 画面の構成
- `style.css`: デザイン、アニメーション、レスポンシブ対応
- `script.js`: 計算ロジック、音声入力、キーボード操作、花火演出

## 実行環境

特別なビルド手順は不要です。モダンなブラウザでそのまま開けます。

音声入力を使用する場合は、Google Chromeとマイクを用意し、ブラウザのマイク使用許可を有効にしてください。
